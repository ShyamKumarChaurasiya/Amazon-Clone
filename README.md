# Amazon Clone

A frontend practice project inspired by Amazon's e-commerce homepage, built using HTML and CSS. This project recreates the basic layout and visual appearance of Amazon's desktop homepage while practicing fundamental frontend web development concepts.

## 📌 About the Project

The Amazon Clone is a static frontend website created to improve my understanding of HTML structure, CSS styling, Flexbox, and webpage layout design.

The project focuses on recreating Amazon's homepage interface, including its navigation bar, search section, hero banner, product categories, and footer.

**Note:** This is a practice project designed for desktop screens. It is not responsive and does not include functional e-commerce features.

## ✨ Features

- Amazon-inspired navigation bar
- Delivery location section
- Search bar with category selector
- Sign-in and account section
- Returns & Orders section
- Shopping cart icon
- Navigation panel with shopping categories
- Hero banner with promotional message
- Eight product and category cards
- Footer with multiple information sections
- Font Awesome icons

## 🛠️ Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, and Flexbox
- **Font Awesome 7.0.1** – Icons

## 🚀 How to Run the Project

1. Clone this repository:

   git clone https://github.com/ShyamKumarChaurasiya/Amazon-Clone

2. Navigate to the project directory:

   cd Amazon-clone


3. Open `index.html` in your browser.

   Alternatively, open the project in VS Code and use the Live Server extension.
